ONLY UNBROKEN REAL 3D V12

Esta versión mantiene el Editor fácil de V11 y reemplaza el falso turntable por un modelo GLB real.
El visor 3D usa OrbitControls: arrastrar para girar y pellizcar para acercar.
Color y capas del editor se sincronizan con el modelo 3D mediante materiales y planos 3D.
El modelo GLB se carga desde un CDN CC0.
